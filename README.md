# To-Do List

Une application web simple et efficace pour gérer mes tâches au quotidien.

## Fonctionnalités
- Ajouter de nouvelles tâches.
- Attribuer les tâches.
- Affecter une date de fin à chaque tâche.
- Signaler les tâches importantes.
- Supprimer les tâches terminées.


## Technologies utilisées
- **HTML5** pour la structure.
- **CSS3** pour le design moderne.
- **JavaScript** pour le dynamisme.
